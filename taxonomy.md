# Shipping Container Sales Site (USA) – Site Taxonomy & Keyword Map

Market: United States (Google US, English). Business model: SELLING containers (new, used, modified). No rental.
Format per page: URL | Page type | H1 | Primary keyword (US monthly vol / KD) | Supporting keywords.
Volumes: OpenSEO / DataForSEO, Nov 2026. KD = keyword difficulty 0-100.

## Build rules
- One primary keyword per page. Never target the same primary on two pages.
- Next.js/React, static-friendly, clean lowercase hyphenated URLs, max 3 levels deep.
- Every product page and category page: Product/Offer schema, price "from $X", size specs table, delivery info, quote/enquiry CTA.
- Every page: unique title (<=60 chars), meta description (<=155), one H1, breadcrumbs + BreadcrumbList schema.
- Internal linking: guides -> category pages -> product pages -> quote. Footer links to all category pages.
- Do NOT build pages for: rental/hire, container tracking, port/terminal, stock terms (navigational/irrelevant).

- Highest-value commercial cluster: "shipping containers for sale" family (~40k, KD ~31) + used (6.6k, KD 17).
